CURRENT STATIC WEBSITE

This is an initial informational notice for the Atomic Corporation static website. It is not a substitute for jurisdiction-specific legal advice and should be reviewed before the company begins collecting personal information or offering paid services.

Information collected by this website

The current website does not provide user accounts, a first-party database, payment processing, or a first-party contact form. It does not currently include an analytics tracker by Atomic Corporation. Do not send private information through a public GitHub issue.

Hosting and third-party services

The website is intended for static hosting through GitHub Pages. Hosting providers may process technical request information under their own policies. The website also loads font files from Google Fonts, which means a visitor's browser may connect to Google infrastructure to retrieve those resources. GitHub and Google have their own privacy terms and practices.

Public inquiries

If you choose to submit an inquiry through GitHub Issues, the submission may be public and may be indexed or copied by others. The data is handled under GitHub's terms and privacy policy. Avoid sharing secrets, private contact details, account credentials, or confidential information in a public issue.

Future changes

If Atomic Corporation introduces accounts, contact forms, analytics, subscriptions, or payment services, this notice must be updated to describe the actual data collected, purposes, retention, service providers, and available user choices before those features launch.

External links

This website may link to third-party websites. Atomic Corporation does not control the content or privacy practices of external services; review their policies before using them.

Contact

The currently published public contact route is listed on the Contact page. Do not submit sensitive information through public channels.
